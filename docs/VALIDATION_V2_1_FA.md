# گزارش بررسی ترب‌یار ۲.۱

تاریخ: 2026-10-23

نسخه تازه‌تر پروژه مبنای تحویل قرار گرفت تا خواندن صفحه‌های عمومی، فرم مراحل خرید، انتخاب امضاشده فروشگاه، اطلاعات قبلی اتصال و بهبودهای نسخه ۲ حفظ شوند. گزارش پیش از این ادغام در `docs/VALIDATION_V2_FA.md` و داده عمومی دریافت قبلی ترب در `artifacts/live-validation.json` باقی مانده‌اند.

| بررسی نسخه ۲.۱ | نتیجه |
| --- | --- |
| آزمون‌های Django | ۱۲۸ آزمون موفق |
| آزمون‌های JavaScript | ۲۴ آزمون موفق |
| آزمون‌های استقرار و bootstrap | ۷ آزمون موفق |
| ساخت React با Vite | موفق |
| بررسی مرورگر واقعی Chromium؛ دسکتاپ و عرض ۳۹۰ پیکسل | ۱۴ بررسی موفق؛ بدون خطای runtime جاوااسکریپت |

در مجموع ۱۵۹ آزمون محلی پاس شده‌اند. آزمون‌ها شامل قواعد رنگ، مدل، نو/کارکرده، سایز، قیمت همان فروشنده، اقساط حضوری، ساعت نامشخص، سؤال قبل از جست‌وجو، تبدیل ریال و ارقام فارسی، قرارداد API گوگل/نشان، ترتیب مختصات، حفظ هویت فروشگاه با امضای سرور، خواندن صفحه عمومی، جلوگیری از دسترسی به آدرس خصوصی، محافظت از کلیدها و مدیریت خطای سرویس‌ها هستند. بررسی‌های تکمیلی، گوگل‌مپ پیش‌فرض، محدوده قیمت متکی به داده، بازه «۲۰ تا ۳۰ میلیون»، دقت نامعتبر GPS و رد سرریز محاسبه اقساط را پوشش می‌دهند.

مرورگر با سرور واقعی Django، خروجی build React و ۴۰۰ محصول/۷۰۱ پیشنهاد از دیتاست واقعی بررسی شد. درخواست چت این بررسی در حالت دیتاست اجرا شد تا تست رابط به دسترسی بیرونی ترب وابسته نباشد. جریان سؤال‌های تکمیلی، نمایش نتایج، رد بازه قیمت نامعتبر پیش از درخواست، گوگل‌مپ پیش‌فرض، انتخاب نشان، فرم داخل فروشگاه، محاسبه مجموع اقساط، بازگشت گفت‌وگوی جدید به بالای صفحه و نبود سرریز افقی موبایل بررسی شدند. این بررسی، تأیید دریافت واقعی تایل‌های نقشه نیست.

## وضعیت اتصال واقعی

- درخواست عمومی مستقل این نوبت به ترب به مهلت اتصال خورد. گزارش دریافت موفق پیشین ترب از نسخه تازه‌تر حفظ شده است؛ آن گزارش snapshot زمان خودش است، نه تضمین موجودی یا قیمت امروز.
- یک درخواست کوچک به مدل تنظیم‌شده BoxAPI هم به مهلت اتصال خورد؛ پاسخ زنده مدل در این محیط تأیید نشد.
- کلید سرویس گوگل، Google Places و کلیدهای نشان برای آزمون زنده در دسترس نبودند؛ قراردادها با پاسخ کنترل‌شده بررسی شدند. سهمیه حساب، دامنه مجاز، دسترسی شبکه و نمایش واقعی نشان با کلید صاحب پروژه باید بررسی شوند.
- Docker در این محیط نصب نبود؛ ساخت image واقعی در این نوبت اجرا نشد. تست‌های تنظیمات و bootstrap موفق شدند و زیرساخت پیشین Docker/لیارا حفظ شده است.

بعد از تنظیم کلیدها، `python backend/manage.py check_services --live` و `python backend/manage.py check_llm` را روی سرور خودت اجرا کن. کلید قبلی AI در فایل خصوصی پروژه حفظ شده است؛ کلیدهای جدید در `.env` قرار می‌گیرند. قیمت، موجودی، تلفن، ساعت، اقساط و طبقه/واحد نامشخص از حدس مدل وارد کارت‌ها نمی‌شوند؛ اطلاعات ثبت‌شده یا اعلام خود کاربر برچسب منبع دارند.
